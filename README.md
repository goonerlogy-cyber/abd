# ABD — Alphabet Board

Click letters **A → Z** in order on a shuffled grid. Wrong picks shake; correct ones lock in green.

## Run

Open `index.html`.

## Files

| File | Role |
|------|------|
| `index.html` | Shell |
| `app.js` | Shuffle + sequential check |
| `styles.css` | Board UI |
